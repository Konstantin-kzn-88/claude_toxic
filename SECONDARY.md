# Вторичное облако HEGADAS — версия 0.6

Ограниченная экспериментальная реализация по HGSYSTEM Technical Reference Manual,
глава 7, HEGADAS: разделы 7.A.2.3 и 7.B. Исходник — предоставленный пользователем
файл «Токси 3 на английском(1).pdf». Название файла не является названием методики.
Соответствие приказу №385 и эквивалентность полному HGSYSTEM не заявляются.
Независимая валидация по экспериментальным данным пока не выполнена.

## Запуск

Python 3.10+:

```bash
python -m pip install -r requirements.txt
python gui.py --secondary
```

В Windows можно использовать `start_secondary.bat`. Консольный запуск:

```bash
python run_secondary.py --input examples/secondary_gas.json --output results_secondary
python -m unittest discover -s tests -q
```

Первичное облако осталось прежним: `start_gui.bat` / `python gui.py`.
Вторичный расчёт совместим с JSON версии 0.5; при отсутствии нового параметра
`plume_options.gaussian_core_fraction` используется 1e-6.

## Область реализации

Постоянная подача сухого идеального газа тяжелее воздуха при атмосферном давлении.
Температуры газа, воздуха и поверхности совпадают и постоянны.
Расход задаётся на входе в приземный шлейф после струйного участка.
Нет опорожнения ёмкости, струи, жидкой фазы, испарения, конденсации, HF-термодинамики,
теплообмена и переноса водяного пара. Это не полная реализация HEGADAS-S/HEGADAS-T.

Начальное эквивалентное сечение: B=H, Sy=0, чистый газ; размер определяется расходом.
Это сохранённое замыкание входных данных программы, а не универсальное условие HGSYSTEM.
X=0 — вход в шлейф, а не центр протяжённого пролива.
Входные alpha_wind и его диапазон высот задаёт пользователь; автоматической
аппроксимации alpha по (A.3) нет. u* рассчитывается через профиль (A.1)-(A.2),
используя прежнее замыкание длины Монина—Обухова по классу устойчивости/шероховатости.
Плотность воздуха по высоте постоянна: профиль температуры/плотности из Appendix A
не реализован. Эти ограничения особенно существенны для высоких облаков.

## Уравнения и соответствие коду

| Источник | Реализация |
|---|---|
| 7.A (2.2), стр. 7-8 | Поперечный профиль с плоским ядром и гауссовскими краями, вертикальный exp(-(z/Sz)^beta), beta=1+alpha |
| (2.4)-(2.8), стр. 7-9—7-10 | B=b+sqrt(pi)/2 Sy; H=Gamma(1/beta)/beta Sz; эффективная скорость; сохранение расхода загрязнителя |
| (2.9)-(2.11), стр. 7-10—7-11 | Верхнее подмешивание; число Ричардсона; uT=u* при отсутствии теплообмена |
| (2.12a)-(2.12b), стр. 7-12 | Гравитационное растекание и критерий его прекращения |
| (2.13), стр. 7-13 | d(Sy²)/dx=4 k_y^e(B) при наличии ядра |
| (2.13*), стр. 7-13 | Гауссовский предел с согласованным виртуальным началом |
| 7.B (3), стр. 7-89 | Рост B после прекращения гравитационного растекания вместо старого (2.12c) |
| 7.B (7.A.2.9*), стр. 7-89—7-90 | Молярное подмешивание после прекращения гравитационного растекания |

sigma(x)=delta*x/sqrt(1+0.0001*x). Время осреднения фиксировано 600 с,
поэтому delta=delta600: A .22; B .16; C .11; D .08; E .06; F .04.
Время осреднения не равно длительности подачи и не равно времени наблюдения.
Для коротких выбросов фиксированное осреднение — ограничение текущей версии.

k_y^e(W)=sigma*sigma'(x_e(sigma)), sigma=sqrt(2/pi)*W.
Обратная функция x_e вычисляется аналитически, используется при текущей ширине,
а не при текущей координате X. Прежнее Sy=sqrt(2)*sigma(X) удалено.

Для (3) раздела 7.B используется k_y*(Sy)=a²*k_y^e(a*Sy), a=sqrt(pi)/2.
Это алгебраическое следствие условия согласования с (2.13) при B=a*Sy,
сформулированного непосредственно под (3); в руководстве функция не расписана отдельно.

При гравитационном растекании dN/dx=2*B*ue/V0. После его прекращения:
dN/dx=2*B*ue/V0 + N/B*dB/dx. Здесь N — полный молярный расход смеси,
V0=0.0224 м³/моль, как в (2.9). Производная массового расхода равна M_air*dN/dx,
поскольку добавляется только воздух. Прежний боковой член с коэффициентом 0.63 удалён.

Эффективная скорость берётся по (2.6) без ограничения H>=0.5 м из приказа №385.
Уравнение состояния смеси использует заданные атмосферные P и T.

## Численные переходы

Интегрируются массовый расход смеси, B, время переноса и Sy²; последнее устраняет
деление на ноль при Sy=0. Критерий (2.12b) — событие интегратора с перезапуском
на уравнениях 7.B, без скачка состояния.

Гауссовский профиль в исправленной модели может достигаться асимптотически.
Поэтому используется явно заданный численный критерий b/B <= gaussian_core_fraction
(по умолчанию 1e-6, допустимо 1e-9…1e-3). При переключении сохраняются B, высота,
массовый расход и осевая концентрация; Sy заменяется на B/a. Относительное изменение
Sy ограничено допуском/(1-допуск). Далее B=a*Sy и выполняется (2.13*).
Это численное приближение предела, а не новый эмпирический критерий HEGADAS.
В JSON записываются координата, остаточная доля ядра и виртуальное начало.
Переход происходит только если достигнут в заданном диапазоне; принудительно
обнулять ядро в конце расчёта программа не будет.

## Конечная подача и результаты

Время переноса: dτ/dx=1/ueff. Концентрация ненулевая при τ(X)<=t<τ(X)+Tподачи.
Это упрощённое перемещение стационарного профиля с резкими передним и задним краями,
а не алгоритм наблюдателей и продольного рассеяния HEGADAS-T.

Сохраняются JSON, CSV, карты PNG X–Y и массивы [Y,X], размеры зон и контрольные точки.
`result.json` содержит `model`, `status`, `transitions`, предупреждения и исходные данные.
Численная область ограничена заданным X<=10000 м и допустимой высотой alpha;
прежнего останова при исчезновении ядра или на 600 с времени переноса нет.
За рассчитанной областью возвращается NaN. Флаг touches_solved_boundary означает,
что дальность зоны не установлена полностью. Границы зон определяются по сетке X.

## Проверки и ограничения доказательств

30 тестов всего, включая прежние проверки первичного облака. Для HEGADAS проверены:
интегральный расход через поперечное сечение с исходным профилем ветра,
молярное подмешивание по обе стороны перехода, непрерывность, аналитический
гауссовский предел с виртуальным началом, устойчивость к уменьшению шага,
сохранение массы после отсечения подачи, изменение расхода и симметрия X–Y.

Длинный тест перехода специально расширяет диапазон alpha до 200 м и использует
допуск ядра 1e-3. Это искусственный численный тест, не подтверждение метеопараметров.
Результаты встроенной демонстрации — не контрольный пример HGSYSTEM.
Раздел 7.A.5 описывает валидацию оригинальной модели; она не переносится автоматически
на этот Python-код. Независимого сравнения полного профиля с экспериментом/оригинальным
HGSYSTEM пока нет, допуск 15% для этой реализации не подтверждён.
