# Основная первичная модель: эмпирическая калибровка

По указанию пользователя от 26.09.2026 поправки включены в основной расчет
`PrimaryCloud`, без переключателя режима. Они действуют в CLI, GUI и первичном
вкладе суммарного облака. Вторичная модель не изменена.
Это эмпирическая модель на основе приказа №385, а не буквальное воспроизведение
его уравнений и не подтверждение сертификации программы.

## Формулы поправок

Пусть u — исходная эффективная скорость, F109 — исходная правая часть уравнения
для d(Sy²)/dt. В основной модели теперь:

    dx/dt = kx u,                       kx = 1.1882598077389053
    d(Sy²)/dt = F109 f(t)
    f(t) = a v^p / (1 + b v) · w^q
    v = min(t/600, 1),                 w = max(t/600, 1)
    a = 1.1826850306787646
    p = 0.9992350415915767
    b = 0.17876511213296598
    q = -0.11924361595098754

Начальное Sy=1e-5 м — как в присланной таблице; для очень малых источников
ограничено сверху 0.001 начального радиуса. Функция f непрерывна при 600 с.
Коэффициенты размерности не имеют. Формула f(t) — подобранная зависимость,
не формула закрытой программы и не установленный физический закон.
Она уже включает эмпирическую зависимость от времени: отдельный множитель
осреднения (t/600)^0.2 одновременно с ней не применяется.

Масса выброшенного вещества, геометрическая связь H=V/(pi R²), термодинамические
уравнения и нормировка концентрации сохранены. Изменение Sy меняет ядро
r=sqrt(R²−Sy²), но не массу интегрального поля концентрации.
В результатах `speed_m_s` обозначает исходную эффективную скорость,
`drift_speed_m_s` — фактическую скорость центра после поправки.

## Данные и подбор

Все 68 строк исходной таблицы сохранены в `reference.csv`.
Из 43 строк с t>=0.01 с чередованием выделены 22 строки подбора и 21 контрольная.
Первые 25 строк не использованы в оптимизации из-за очень малого времени
и округления начальной дисперсии; они сохранены и проверяются при сравнении.
Списки строк и коэффициенты — `fit_parameters.json`.
Последняя строка t=1820.932373 с использована для подбора, но находится за
производственным пределом экспозиции 1800 с и явно исключена из сравнения
готового расчета. Проверено 67/68 строк готовой модели.

kx найден минимизацией квадрата логарифмического отношения координат.
Четыре параметра f(t) определены методом наименьших квадратов для log(Sy/Sy_ref).
Зоны токсодозы не использовались как цели оптимизации.
Контрольные строки принадлежат той же аварии: это проверка интерполяции,
а не независимая валидация. Форма эмпирической зависимости выбрана после
предварительного изучения всей таблицы; контроль не является слепым экспериментом.

Воспроизведение из корня репозитория:

```sh
python fit_primary_calibration.py
python validate_chlorine.py
python validate_chlorine_zones.py
python -m unittest discover -s tests -q
```

Первый скрипт пишет кандидатов в `results_chlorine_validation/fit_candidate.json`,
но не перезаписывает коэффициенты основного расчета. Результаты остальных
проверок сохраняются в той же папке. Исходный анализ до калибровки — README.md.

При уменьшении шага токсодозы с 0.25 до 0.125 с изменение приведенных границ

Стандартная карта GUI использует конечную пространственную сетку; ее дискретные
границы могут отличаться. Остаток полуширины PCt не объясняется шагом времени.

## Применимость и запуск в GUI

Для готового случая открыть `examples/chlorine_calibrated.json` через «Открыть JSON».
Расчет за 1800 с разрешен; значения по умолчанию для длительности других проектов
не менялись. Ограничения по тяжелому газу, исчезновению ядра, температуре,
высоте профиля и дальности 10 км продолжают останавливать расчет.
В контрольном примере alpha=0.65 условно постоянно до 40 м — это явно записанное
эмпирическое допущение, а не интерполяция нормативной таблицы. Стандартный предел
профиля 20 м для остальных проектов автоматически не повышается.

Калибровка относится к одному случаю: 1000 кг хлора, 0.11 МПа абсолютного
давления, 40 °C, ветер 1 м/с на 10 м, F, z0=0.55 м, alpha=0.65.
В основном режиме поправки применяются и к другим данным по решению пользователя,
но точность для других веществ, масс, температур, классов устойчивости и ветра
не установлена. В `result.json` первичного и суммарного расчета сохраняются
`primary_calibration`, коэффициенты, область исходного примера и отсутствие
независимой валидации. Повторный расчет старого проекта даст другие результаты.
